# ArisFrontEnd

Proyecto React + TypeScript creado con Vite.

## Ejecutar

```powershell
cd ArisFrontEnd
npm install
npm run dev
```

Abre `http://localhost:5173`.

## Estructura

- `src/App.tsx` - componente principal
- `src/main.tsx` - entrada de React
- `src/App.css` - estilos del diseño
- `src/index.css` - estilos globales
